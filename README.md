# ZEN

Personal knowledge system: a markdown vault that holds notes and original documents, a deterministic indexer, local hybrid search (qmd), a Brain-First rulebook for Claude, and a Claude-maintained wiki that marks contradictions instead of overwriting them.

Sub-project of mabstruct. Lighter sibling of CONSTRUCT: files and rules instead of pipelines.
