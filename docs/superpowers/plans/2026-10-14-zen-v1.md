# ZEN v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A markdown vault with originals and companions, a deterministic indexer (INDEX.md + map.json), qmd local hybrid search, a Brain-First rulebook for Claude Code, and a Claude-maintained wiki that marks contradictions instead of overwriting them.

**Architecture:** `zen/tools/` is a small `uv` Python package with two CLIs, `zen-index` (vault → INDEX.md + `_meta/map.json`, no AI) and `zen-intake` (file/URL/arXiv/DOI → original in `_originals/` + markdown companion, no AI). qmd is installed as-is and configured project-locally in `zen/.qmd/`. Claude Code skills under `zen/.claude/skills/` call the CLIs and carry the rules; `zen/CLAUDE.md` holds the Brain-First ladder; `vault/90_wiki/SCHEMA.md` holds the wiki rules. Only `/zen-ask` and `/zen-ingest` spend tokens.

**Tech Stack:** Python ≥3.12 (venv pinned 3.13) via `uv`; PyYAML; `markitdown[pdf,docx,pptx,xlsx]`; pytest; qmd (`@tobilu/qmd`, Node); Claude Code skills (markdown).

**Spec:** `docs/superpowers/specs/2026-10-14-zen-design.md` — read it first; this plan argues from it.

## Global Constraints

- Markdown is the only truth. Tools never write into `vault/` except: intake writes companions/originals/normalised notes; the indexer writes only `vault/INDEX.md` and `vault/_meta/map.json`.
- No AI, no network in `zen-index`. No AI in `zen-intake` (network only to fetch a given URL/arXiv/DOI).
- All timestamps ISO 8601 with UTC offset, seconds precision, e.g. `2026-10-14T18:02:11+02:00`. Frontmatter stores them as strings, never YAML timestamps.
- Cluster is derived from the first path component (`1x_<name>`), never stored in frontmatter.
- Links: standard relative markdown links; `[[wikilinks]]` are also parsed.
- Filenames are slugs: lowercase ASCII, hyphens, ≤ 80 chars before the extension.
- Generated files (`INDEX.md`, `_meta/`) and `90_wiki/` are never hand-edited.
- Idempotence: re-running `zen-index` or `zen-intake` on unchanged inputs changes nothing.
- All shell commands below run from `/Users/mab/dev/mabstruct/zen` unless a `cd` says otherwise; `uv run` commands run from `tools/`.
- Commits go to the `zen` git repository (already initialised, branch `main`). Commit message footer: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. A markdown link whose target contains `%20` or a literal space must resolve to the existing file, not be reported as broken. — test in Task 2.
2. `tags:` written as a single string (`tags: ai`) instead of a list must be read as `["ai"]`, not iterated as characters. — test in Task 2.
3. A URL that returns `Content-Type: text/html; charset=utf-8` must be saved as `.html` and extracted; the charset suffix must not break type detection. — test in Task 7.
4. Intaking the same document twice from a path outside the inbox must report `duplicate` on the second run and write nothing. — test in Task 9.
5. A file whose `updated` equals its `ingested` timestamp is **not** "wiki behind"; only strictly newer counts. — test in Task 3.

```python
from __future__ import annotations

import re
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

import yaml

_FM_RE = re.compile(r"\A---\r?\n(.*?)\r?\n---\r?\n?", re.DOTALL)
_TIMESTAMP_TAG = "tag:yaml.org,2002:timestamp"


def _without_timestamp_resolver(base):
    cls = type(base.__name__ + "NoTs", (base,), {})
    cls.yaml_implicit_resolvers = {
        key: [(tag, regexp) for (tag, regexp) in resolvers if tag != _TIMESTAMP_TAG]
        for key, resolvers in base.yaml_implicit_resolvers.items()
    }
    return cls


_Loader = _without_timestamp_resolver(yaml.SafeLoader)
_Dumper = _without_timestamp_resolver(yaml.SafeDumper)


@dataclass
class Document:
    meta: dict
    body: str


def parse(text: str) -> Document:
    m = _FM_RE.match(text)
    if not m:
        return Document({}, text)
    meta = yaml.load(m.group(1), Loader=_Loader) or {}
    if not isinstance(meta, dict):
        raise ValueError("frontmatter is not a mapping")
    return Document(meta, text[m.end():])


def dump(doc: Document) -> str:
    meta = yaml.dump(
        doc.meta, Dumper=_Dumper, sort_keys=False, allow_unicode=True, default_flow_style=False
    ).rstrip("\n")
    return f"---\n{meta}\n---\n{doc.body}"


def now_iso() -> str:
    return datetime.now().astimezone().replace(microsecond=0).isoformat()


def read(path: Path) -> Document:
    return parse(path.read_text(encoding="utf-8"))


def write(path: Path, doc: Document) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(dump(doc), encoding="utf-8")
```

```python
from __future__ import annotations

import os
import re
from dataclasses import dataclass, field
from datetime import datetime
from pathlib import Path, PurePosixPath
from urllib.parse import unquote

from . import frontmatter as fm

SKIP_DIRS = {"_meta", "_originals", "02_templates", ".git", ".qmd", ".obsidian"}
GENERATED_FILES = {"INDEX.md"}
MD_LINK_RE = re.compile(r"(?<!!)\[[^\]]*\]\(([^)\s#]+)(?:#[^)]*)?\)")
WIKILINK_RE = re.compile(r"\[\[([^\]|#]+)(?:#[^\]|]*)?(?:\|[^\]]*)?\]\]")
CONFLICT_RE = re.compile(r"^> \[!conflict\] (#c-\d+) — open\s*$", re.M)
HEADING_RE = re.compile(r"^#\s+(.+?)\s*$", re.M)
CLUSTER_RE = re.compile(r"^1\d_")


@dataclass
class Doc:
    rel: str
    cluster: str | None
    title: str
    type: str
    tags: list[str]
    meta: dict
    links: list[str]
    summary: str
    created: str | None
    updated: str
    captured: str | None
    ingested: str | None
    size: int
    open_conflicts: list[str] = field(default_factory=list)
    inbound: int = 0


@dataclass
class Cluster:
    name: str
    description: str
    notes: int = 0
    companions: int = 0
    originals: int = 0


@dataclass
class VaultScan:
    root: Path
    docs: dict[str, Doc]
    clusters: list[Cluster]
    originals: list[str]
    broken_links: list[tuple[str, str]]
    inbox: list[str]


def cluster_of(rel: str) -> str | None:
    head = PurePosixPath(rel).parts[0]
    return head if re.match(r"^\d\d_", head) else None


def _mtime_iso(path: Path) -> str:
    return datetime.fromtimestamp(path.stat().st_mtime).astimezone().replace(microsecond=0).isoformat()


def _summary_of(body: str) -> str:
    in_summary = False
    for line in body.splitlines():
        if line.startswith("## "):
            if in_summary:
                return ""
            in_summary = line.strip() == "## Summary"
            continue
        if in_summary and line.strip():
            return line.strip()
    return ""


def _tags_of(meta: dict) -> list[str]:
    raw = meta.get("tags")
    if raw is None:
        return []
    if isinstance(raw, str):
        return [raw]
    return [str(t) for t in raw]


def _title_of(meta: dict, body: str, path: Path) -> str:
    if meta.get("title"):
        return str(meta["title"])
    m = HEADING_RE.search(body)
    return m.group(1) if m else path.stem


def _type_of(meta: dict, rel: str) -> str:
    if meta.get("type"):
        return str(meta["type"])
    return "wiki-meta" if rel.startswith("90_wiki/") else "note"


def _raw_links(body: str) -> tuple[list[str], list[str]]:
    md = [unquote(t) for t in MD_LINK_RE.findall(body) if "://" not in t and not t.startswith("mailto:")]
    wiki = [w.strip() for w in WIKILINK_RE.findall(body)]
    return md, wiki


def _resolve_md(rel_dir: PurePosixPath, target: str) -> str:
    joined = rel_dir / target if not target.startswith("/") else PurePosixPath(target.lstrip("/"))
    parts: list[str] = []
    for part in joined.parts:
        if part == "..":
            if parts:
                parts.pop()
        elif part != ".":
            parts.append(part)
    out = "/".join(parts)
    return out if out.endswith(".md") else out + ".md"


def scan(root: Path) -> VaultScan:
    root = root.resolve()
    docs: dict[str, Doc] = {}
    originals: list[str] = []
    pending_wikilinks: dict[str, list[str]] = {}
    cluster_desc: dict[str, str] = {}
    cluster_dirs: list[str] = []

    for dirpath, dirnames, filenames in os.walk(root):
        rel_dir = PurePosixPath(Path(dirpath).relative_to(root).as_posix()) if dirpath != str(root) else PurePosixPath()
        if rel_dir.parts and rel_dir.parts[0] not in cluster_dirs and CLUSTER_RE.match(rel_dir.parts[0]):
            cluster_dirs.append(rel_dir.parts[0])
        if Path(dirpath).name == "_originals":
            for f in filenames:
                if not f.startswith("."):
                    originals.append((rel_dir / f).as_posix())
            dirnames[:] = []
            continue
        dirnames[:] = sorted(d for d in dirnames if d not in SKIP_DIRS or d == "_originals")
        for f in sorted(filenames):
            if not f.endswith(".md") or f.startswith("."):
                continue
            rel = (rel_dir / f).as_posix()
            if rel in GENERATED_FILES:
                continue
            path = root / rel
            if f == "_cluster.md":
                text = path.read_text(encoding="utf-8").strip()
                cluster_desc[rel_dir.parts[0]] = text.splitlines()[0] if text else ""
                continue
            doc = fm.read(path)
            md_links, wiki_links = _raw_links(doc.body)
            links = [_resolve_md(rel_dir, t) for t in md_links]
            pending_wikilinks[rel] = wiki_links
            docs[rel] = Doc(
                rel=rel,
                cluster=cluster_of(rel),
                title=_title_of(doc.meta, doc.body, path),
                type=_type_of(doc.meta, rel),
                tags=_tags_of(doc.meta),
                meta=doc.meta,
                links=links,
                summary=_summary_of(doc.body),
                created=doc.meta.get("created"),
                updated=doc.meta.get("updated") or _mtime_iso(path),
                captured=(doc.meta.get("source") or {}).get("captured") if isinstance(doc.meta.get("source"), dict) else None,
                ingested=doc.meta.get("ingested"),
                size=path.stat().st_size,
                open_conflicts=CONFLICT_RE.findall(doc.body),
            )

    by_title = {d.title.lower(): d.rel for d in docs.values()}
    by_stem = {PurePosixPath(d.rel).stem.lower(): d.rel for d in docs.values()}
    broken: list[tuple[str, str]] = []
    for rel, names in pending_wikilinks.items():
        for name in names:
            target = by_title.get(name.lower()) or by_stem.get(name.lower())
            if target:
                docs[rel].links.append(target)
            else:
                broken.append((rel, name))
    for d in docs.values():
        for target in d.links:
            if target in docs:
                docs[target].inbound += 1
            elif (d.rel, target) not in broken:
                broken.append((d.rel, target))

    clusters: list[Cluster] = []
    for name in sorted(cluster_dirs):
        c = Cluster(name=name, description=cluster_desc.get(name) or name)
        for d in docs.values():
            if d.cluster == name:
                if d.type == "companion":
                    c.companions += 1
                else:
                    c.notes += 1
        c.originals = sum(1 for o in originals if o.startswith(name + "/"))
        clusters.append(c)

    inbox = sorted(rel for rel in docs if rel.startswith("00_inbox/"))
    return VaultScan(root=root, docs=docs, clusters=clusters, originals=sorted(originals), broken_links=broken, inbox=inbox)
```

```python
from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass
from datetime import datetime, timedelta

from .vault import VaultScan

KINDS = (
    "inbox-stale",
    "snapshot-missing",
    "extraction-failed",
    "large-file",
    "orphan",
    "broken-link",
    "duplicate-title",
    "never-ingested",
    "wiki-behind",
    "open-conflict",
)
CONTENT_TYPES = {"note", "companion", "daily"}


@dataclass
class Finding:
    kind: str
    path: str
    detail: str = ""


def _ts(s: str | None) -> datetime | None:
    return datetime.fromisoformat(s) if s else None


def check(scan: VaultScan, now: datetime, inbox_days: int = 7) -> list[Finding]:
    out: list[Finding] = []
    docs = scan.docs

    cutoff = now - timedelta(days=inbox_days)
    for rel in scan.inbox:
        d = docs[rel]
        when = _ts(d.created) or _ts(d.updated)
        if when and when < cutoff:
            out.append(Finding("inbox-stale", rel, f"since {when.date()}"))

    for d in docs.values():
        if d.meta.get("snapshot") == "missing":
            out.append(Finding("snapshot-missing", d.rel, str((d.meta.get("source") or {}).get("url", ""))))
    for d in docs.values():
        if d.meta.get("extraction") == "failed":
            out.append(Finding("extraction-failed", d.rel))
    for d in docs.values():
        if d.meta.get("large") is True:
            out.append(Finding("large-file", d.rel))

    for d in docs.values():
        if d.type in CONTENT_TYPES and d.inbound == 0 and not any(t in docs for t in d.links):
            out.append(Finding("orphan", d.rel))

    for src, target in scan.broken_links:
        out.append(Finding("broken-link", src, target))

    titles: dict[str, list[str]] = defaultdict(list)
    for d in docs.values():
        if d.type != "wiki-meta":
            titles[d.title.strip().lower()].append(d.rel)
    for title, rels in sorted(titles.items()):
        if len(rels) > 1:
            for rel in sorted(rels):
                out.append(Finding("duplicate-title", rel, title))

    for d in docs.values():
        if d.type in CONTENT_TYPES and d.ingested is None:
            out.append(Finding("never-ingested", d.rel))
    for d in docs.values():
        if d.type in CONTENT_TYPES and d.ingested is not None:
            upd, ing = _ts(d.updated), _ts(d.ingested)
            if upd and ing and upd > ing:
                out.append(Finding("wiki-behind", d.rel, f"updated {d.updated} > ingested {d.ingested}"))

    for d in docs.values():
        for cid in d.open_conflicts:
            out.append(Finding("open-conflict", d.rel, cid))

    out.sort(key=lambda f: (KINDS.index(f.kind), f.path, f.detail))
    return out
```

```python
from __future__ import annotations

from collections import defaultdict
from datetime import datetime

from .health import KINDS, Finding
from .vault import Doc, VaultScan

INBOUND_THRESHOLD = 3


def is_important(doc: Doc) -> bool:
    return bool(doc.summary) or doc.inbound >= INBOUND_THRESHOLD or "pinned" in doc.tags


def _line(doc: Doc) -> str:
    parts = [f"- [{doc.title}]({doc.rel})"]
    detail = [doc.summary] if doc.summary else []
    if doc.tags:
        detail.append(" ".join(doc.tags))
    detail.append(f"updated {doc.updated[:10]}")
    return parts[0] + " — " + " · ".join(detail)


def render(scan: VaultScan, findings: list[Finding], now: datetime) -> str:
    docs = scan.docs.values()
    notes = sum(1 for d in docs if d.type in {"note", "daily"})
    companions = sum(1 for d in docs if d.type == "companion")
    wiki_pages = sum(1 for d in docs if d.type.startswith("wiki-") and d.type != "wiki-meta")
    open_conflicts = sum(1 for f in findings if f.kind == "open-conflict")

    out = ["# ZEN Index", ""]
    out.append(
        f"Generated {now.isoformat()} · {notes} notes · {companions} companions · "
        f"{len(scan.originals)} originals · {wiki_pages} wiki pages · {open_conflicts} open conflicts"
    )
    out.append("")
    out.append("Read this first. Open exactly the file you need. Regenerate with `zen-index`; never edit by hand.")
    out.append("")

    for c in scan.clusters:
        out.append(f"## {c.name}")
        out.append("")
        out.append(f"{c.description} — {c.notes} notes · {c.companions} companions · {c.originals} originals")
        out.append("")
        important = [d for d in docs if d.cluster == c.name and is_important(d)]
        for d in sorted(important, key=lambda d: (d.updated, d.rel), reverse=True):
            out.append(_line(d))
        if important:
            out.append("")

    out.append("## Wiki")
    out.append("")
    by_type: dict[str, list[Doc]] = defaultdict(list)
    for d in docs:
        if d.type.startswith("wiki-") and d.type != "wiki-meta":
            by_type[d.type].append(d)
    for t in sorted(by_type):
        out.append(f"### {t}")
        for d in sorted(by_type[t], key=lambda d: d.rel):
            out.append(f"- [{d.title}]({d.rel})")
        out.append("")
    if not by_type:
        out.append("No wiki pages yet. Run `/zen-ingest`.")
        out.append("")

    out.append("## Health")
    out.append("")
    by_kind: dict[str, list[Finding]] = defaultdict(list)
    for f in findings:
        by_kind[f.kind].append(f)
    if not findings:
        out.append("Clean.")
        out.append("")
    for kind in KINDS:
        if kind not in by_kind:
            continue
        out.append(f"### {kind}")
        for f in by_kind[kind]:
            out.append(f"- {f.path} — {f.detail}" if f.detail else f"- {f.path}")
        out.append("")
    return "\n".join(out).rstrip("\n") + "\n"
```

```python
from __future__ import annotations

from datetime import datetime
from pathlib import PurePosixPath

from .vault import VaultScan, cluster_of


def build(scan: VaultScan, now: datetime) -> dict:
    nodes: dict[str, dict] = {}
    edges: list[dict] = []

    for d in scan.docs.values():
        nodes[d.rel] = {
            "id": d.rel, "path": d.rel, "title": d.title, "type": d.type, "cluster": d.cluster,
            "tags": d.tags, "size": d.size, "created": d.created, "updated": d.updated,
            "captured": d.captured, "ingested": d.ingested,
        }
    for o in scan.originals:
        nodes[o] = {
            "id": o, "path": o, "title": PurePosixPath(o).name, "type": "original", "cluster": cluster_of(o),
            "tags": [], "size": (scan.root / o).stat().st_size, "created": None, "updated": None,
            "captured": None, "ingested": None,
        }
    for d in scan.docs.values():
        for t in d.tags:
            tid = f"tag:{t}"
            nodes.setdefault(tid, {"id": tid, "path": None, "title": t, "type": "tag", "cluster": None, "tags": [],
                                    "size": 0, "created": None, "updated": None, "captured": None, "ingested": None})

    def add(frm: str, to: str, kind: str) -> None:
        if frm in nodes and to in nodes:
            edges.append({"from": frm, "to": to, "kind": kind})

    for d in scan.docs.values():
        for t in d.links:
            add(d.rel, t, "link")
        for t in d.tags:
            add(d.rel, f"tag:{t}", "tag")
        src = d.meta.get("source")
        if isinstance(src, dict) and src.get("local") and d.cluster:
            add(d.rel, f"{d.cluster}/{src['local']}", "source")
        for s in d.meta.get("sources") or []:
            add(d.rel, str(s), "wiki")

    edges.sort(key=lambda e: (e["from"], e["to"], e["kind"]))
    return {"generated": now.isoformat(), "nodes": [nodes[k] for k in sorted(nodes)], "edges": edges}
```

```python
from __future__ import annotations

import argparse
import json
import os
import sys
from datetime import datetime
from pathlib import Path

from . import health, index_md, map_json
from .vault import SKIP_DIRS, scan

OUTPUTS = ("INDEX.md", "_meta/map.json")


def _content_mtime(vault: Path) -> float:
    latest = 0.0
    for dirpath, dirnames, filenames in os.walk(vault):
        dirnames[:] = [d for d in dirnames if d not in (SKIP_DIRS - {"_originals"})]
        for f in filenames:
            p = Path(dirpath) / f
            rel = p.relative_to(vault).as_posix()
            if rel in OUTPUTS or f.startswith("."):
                continue
            latest = max(latest, p.stat().st_mtime)
    return latest


def is_stale(vault: Path) -> bool:
    index = vault / "INDEX.md"
    if not index.exists() or not (vault / "_meta" / "map.json").exists():
        return True
    return _content_mtime(vault) > index.stat().st_mtime


def run(vault: Path, check: bool = False, now: datetime | None = None) -> int:
    vault = vault.resolve()
    if check:
        if is_stale(vault):
            print(f"stale: {vault / 'INDEX.md'} is older than vault content — run zen-index", file=sys.stderr)
            return 1
        print("index is current")
        return 0
    now = now or datetime.now().astimezone().replace(microsecond=0)
    s = scan(vault)
    findings = health.check(s, now)
    text = index_md.render(s, findings, now)
    (vault / "_meta").mkdir(exist_ok=True)
    (vault / "INDEX.md").write_text(text, encoding="utf-8")
    (vault / "_meta" / "map.json").write_text(json.dumps(map_json.build(s, now), indent=1, ensure_ascii=False) + "\n", encoding="utf-8")
    print(text.splitlines()[2])
    print()
    print("## Health" + text.split("## Health", 1)[1])
    return 0


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="zen-index", description="Rebuild vault/INDEX.md and vault/_meta/map.json.")
    ap.add_argument("--vault", type=Path, default=Path("vault"))
    ap.add_argument("--check", action="store_true", help="exit 1 if INDEX.md is older than vault content")
    a = ap.parse_args(argv)
    return run(a.vault, check=a.check)


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
from __future__ import annotations

import hashlib
import re
import unicodedata
import urllib.request
from dataclasses import dataclass
from pathlib import Path
from typing import Callable
from urllib.parse import urlparse

Fetcher = Callable[[str], tuple[bytes, str]]

_ARXIV_ID = r"(\d{4}\.\d{4,5}(?:v\d+)?)"
ARXIV_URL_RE = re.compile(r"^https?://(?:www\.)?arxiv\.org/(?:abs|pdf)/" + _ARXIV_ID + r"(?:\.pdf)?/?$", re.I)
ARXIV_BARE_RE = re.compile(r"^(?:arxiv:)?" + _ARXIV_ID + r"$", re.I)
DOI_RE = re.compile(r"^(?:https?://(?:dx\.)?doi\.org/|doi:)?(10\.\d{4,9}/\S+)$", re.I)
USER_AGENT = "zen-intake/0.1 (+https://github.com/mabstruct/zen)"
PDF_TYPES = ("application/pdf", "application/x-pdf")


@dataclass
class Resolved:
    kind: str
    url: str | None
    filename: str
    data: bytes | None
    error: str | None = None


def classify(spec: str) -> tuple[str, str]:
    s = spec.strip()
    if m := ARXIV_URL_RE.match(s):
        return "arxiv", m.group(1)
    if m := ARXIV_BARE_RE.match(s):
        return "arxiv", m.group(1)
    if m := DOI_RE.match(s):
        return "doi", m.group(1)
    if re.match(r"^https?://", s, re.I):
        return "url", s
    return "file", s


def slugify(name: str, max_len: int = 80) -> str:
    stem, dot, ext = name.rpartition(".")
    if not dot or "/" in ext or " " in ext or len(ext) > 5:
        stem, ext = name, ""
    stem = unicodedata.normalize("NFKD", stem).encode("ascii", "ignore").decode()
    stem = re.sub(r"[^a-z0-9]+", "-", stem.lower()).strip("-")[:max_len].strip("-") or "untitled"
    return f"{stem}.{ext.lower()}" if ext else stem


def sha256(data: bytes) -> str:
    return "sha256:" + hashlib.sha256(data).hexdigest()


def default_fetch(url: str) -> tuple[bytes, str]:
    req = urllib.request.Request(url, headers={"User-Agent": USER_AGENT, "Accept": "application/pdf, text/html;q=0.9, */*;q=0.5"})
    with urllib.request.urlopen(req, timeout=60) as resp:
        return resp.read(), resp.headers.get("Content-Type", "") or ""


def _ext_for(content_type: str, fallback: str) -> str:
    ct = content_type.split(";")[0].strip().lower()
    if ct in PDF_TYPES:
        return "pdf"
    if ct in ("text/html", "application/xhtml+xml"):
        return "html"
    if ct == "text/plain":
        return "txt"
    if ct == "text/markdown":
        return "md"
    return fallback


def _url_slug(url: str) -> str:
    u = urlparse(url)
    return slugify((u.netloc + u.path).rstrip("/") or u.netloc)


def resolve(spec: str, fetch: Fetcher = default_fetch) -> Resolved:
    kind, ident = classify(spec)
    if kind == "file":
        p = Path(ident)
        if not p.is_file():
            return Resolved("file", None, slugify(p.name), None, f"file not found: {ident}")
        return Resolved("file", None, slugify(p.name), p.read_bytes())
    if kind == "arxiv":
        fetch_url, url, base = f"https://arxiv.org/pdf/{ident}", f"https://arxiv.org/abs/{ident}", ident
    elif kind == "doi":
        fetch_url = url = f"https://doi.org/{ident}"
        base = slugify(ident.replace("/", "-"))
    else:
        fetch_url = url = ident
        base = _url_slug(ident)
    try:
        data, ctype = fetch(fetch_url)
    except Exception as e:  # network boundary: any failure is reported, never raised
        fallback = "pdf" if kind in ("arxiv", "doi") else "html"
        return Resolved(kind, url, f"{base}.{fallback}", None, f"{type(e).__name__}: {e}")
    ext = _ext_for(ctype, "pdf" if kind in ("arxiv", "doi") else "html")
    return Resolved(kind, url, f"{base}.{ext}", data)
```

```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

OPAQUE_EXT = {".png", ".jpg", ".jpeg", ".gif", ".webp", ".heic", ".svg", ".bmp", ".tiff", ".tif"}


@dataclass
class Extraction:
    status: str
    markdown: str
    title: str | None
    error: str | None = None


def extract(path: Path) -> Extraction:
    if path.suffix.lower() in OPAQUE_EXT:
        return Extraction("none", "", None)
    if path.suffix.lower() in {".md", ".txt"}:
        return Extraction("ok", path.read_text(encoding="utf-8", errors="replace"), None)
    try:
        from markitdown import MarkItDown

        result = MarkItDown(enable_plugins=False).convert(str(path))
        text = (result.markdown or "").strip()
        if not text:
            return Extraction("failed", "", result.title, "empty extraction")
        return Extraction("ok", text + "\n", result.title or None)
    except Exception as e:  # third-party boundary: every failure becomes a flagged companion
        return Extraction("failed", "", None, f"{type(e).__name__}: {e}")
```

- Consumes: `sources.resolve`, `sources.sha256`, `sources.slugify`, `extract.extract`, `vault.scan`, `frontmatter.*`.

Behaviour:
- Target folder = `vault/<cluster>` if `cluster` names an existing `1x_` folder, else `vault/00_inbox` (status `inbox`). An unknown cluster name is an error (status `failed`), not a silent fallback.
- Originals go to `<target>/_originals/<slug>`; companion to `<target>/<stem>.md`. Name collision with different content → suffix `-2`, `-3`, …
- A local file *inside* `vault/00_inbox/` is moved; a local file elsewhere is copied.
- Raw `.md` in the inbox: frontmatter normalised (`title`, `type: note`, `created`, `updated`, `tags` list); `cluster:` key in its frontmatter is consumed as the cluster and removed; moved to the cluster or left in place.
- Companion frontmatter per spec §4, body `## Summary\n\n## Extracted text\n<text>`.
- Never modifies an existing companion/note; never deletes except the inbox move.

```python
from __future__ import annotations

import shutil
from dataclasses import dataclass, field
from pathlib import Path, PurePosixPath

from . import frontmatter as fm, sources
from .extract import extract
from .vault import CLUSTER_RE, scan

LARGE_BYTES = 50 * 1024 * 1024
INBOX = "00_inbox"


@dataclass
class ItemResult:
    input: str
    status: str
    companion: str | None = None
    original: str | None = None
    note: str = ""


@dataclass
class Report:
    items: list[ItemResult] = field(default_factory=list)

    def summary(self) -> str:
        counts = {s: sum(1 for i in self.items if i.status == s) for s in ("filed", "inbox", "duplicate", "failed")}
        lines = [", ".join(f"{k}: {v}" for k, v in counts.items())]
        for i in self.items:
            where = i.companion or "-"
            lines.append(f"  {i.status:9} {i.input} -> {where}{(' (' + i.note + ')') if i.note else ''}")
        return "\n".join(lines)


def _target_dir(vault: Path, cluster: str | None) -> tuple[Path, str] | str:
    if cluster is None:
        return vault / INBOX, "inbox"
    if not CLUSTER_RE.match(cluster) or not (vault / cluster).is_dir():
        return f"unknown cluster: {cluster}"
    return vault / cluster, "filed"


def _free(path: Path) -> Path:
    if not path.exists():
        return path
    n = 2
    while True:
        cand = path.with_name(f"{path.stem}-{n}{path.suffix}")
        if not cand.exists():
            return cand
        n += 1


def _existing_hashes(vault: Path) -> dict[str, str]:
    out: dict[str, str] = {}
    for d in scan(vault).docs.values():
        src = d.meta.get("source")
        if isinstance(src, dict) and src.get("hash"):
            out[src["hash"]] = d.rel
    return out


def intake_item(vault: Path, spec: str, cluster: str | None, *, fetch=sources.default_fetch, now: str | None = None) -> ItemResult:
    vault = vault.resolve()
    now = now or fm.now_iso()
    target = _target_dir(vault, cluster)
    if isinstance(target, str):
        return ItemResult(spec, "failed", note=target)
    target_dir, status = target

    res = sources.resolve(spec, fetch=fetch)
    if res.kind == "file" and res.data is None:
        return ItemResult(spec, "failed", note=res.error or "unreadable")

    source: dict = {"kind": res.kind}
    if res.url:
        source["url"] = res.url
    meta: dict = {"title": "", "type": "companion", "created": now, "updated": now, "tags": [], "source": source}
    body_text = ""
    original_rel: str | None = None
    stem = PurePosixPath(res.filename).stem

    if res.data is None:
        source["captured"] = now
        meta["snapshot"] = "missing"
        meta["extraction"] = "none"
        meta["title"] = res.url or stem
    else:
        h = sources.sha256(res.data)
        dup = _existing_hashes(vault).get(h)
        if dup:
            return ItemResult(spec, "duplicate", companion=dup, note="same content already in vault")
        orig_path = _free(target_dir / "_originals" / res.filename)
        orig_path.parent.mkdir(parents=True, exist_ok=True)
        src_path = Path(spec) if res.kind == "file" else None
        if src_path and src_path.resolve().is_relative_to(vault / INBOX):
            shutil.move(str(src_path), orig_path)
        else:
            orig_path.write_bytes(res.data)
        stem = orig_path.stem
        ex = extract(orig_path)
        source.update({"local": f"_originals/{orig_path.name}", "hash": h, "captured": now})
        meta["snapshot"] = "ok"
        meta["extraction"] = ex.status
        if ex.error:
            meta["extraction_error"] = ex.error
        if len(res.data) > LARGE_BYTES:
            meta["large"] = True
        meta["title"] = ex.title or _heading(ex.markdown) or stem
        body_text = ex.markdown
        original_rel = orig_path.relative_to(vault).as_posix()

    comp_path = _free(target_dir / f"{stem}.md")
    fm.write(comp_path, fm.Document(meta, "## Summary\n\n## Extracted text\n" + body_text))
    return ItemResult(spec, status, companion=comp_path.relative_to(vault).as_posix(), original=original_rel,
                      note=(res.error or "") if res.data is None else "")


def _heading(markdown: str) -> str | None:
    for line in markdown.splitlines():
        if line.startswith("# "):
            return line[2:].strip()
    return None


def _normalise_note(path: Path, now: str) -> tuple[fm.Document, str | None]:
    doc = fm.read(path)
    cluster = doc.meta.pop("cluster", None)
    tags = doc.meta.get("tags")
    doc.meta["tags"] = [tags] if isinstance(tags, str) else [str(t) for t in (tags or [])]
    doc.meta.setdefault("title", _heading(doc.body) or path.stem)
    doc.meta.setdefault("type", "note")
    doc.meta.setdefault("created", now)
    doc.meta.setdefault("updated", now)
    ordered = {k: doc.meta[k] for k in ("title", "type", "created", "updated", "tags") if k in doc.meta}
    ordered.update({k: v for k, v in doc.meta.items() if k not in ordered})
    return fm.Document(ordered, doc.body), (str(cluster) if cluster else None)


def intake_inbox(vault: Path, cluster: str | None, *, fetch=sources.default_fetch, now: str | None = None) -> Report:
    vault = vault.resolve()
    now = now or fm.now_iso()
    inbox = vault / INBOX
    report = Report()
    for path in sorted(inbox.iterdir()):
        if path.is_dir() or path.name.startswith("."):
            continue
        rel = path.relative_to(vault).as_posix()
        if path.suffix.lower() == ".md":
            doc, note_cluster = _normalise_note(path, now)
            chosen = cluster or note_cluster
            target = _target_dir(vault, chosen)
            if isinstance(target, str):
                report.items.append(ItemResult(rel, "failed", note=target))
                continue
            target_dir, status = target
            if status == "inbox":
                fm.write(path, doc)
                report.items.append(ItemResult(rel, "inbox", companion=rel, note="no cluster"))
            else:
                dest = _free(target_dir / path.name)
                fm.write(dest, doc)
                path.unlink()
                report.items.append(ItemResult(rel, "filed", companion=dest.relative_to(vault).as_posix()))
        else:
            report.items.append(intake_item(vault, str(path), cluster, fetch=fetch, now=now))
    return report
```

```python
        index_cli.run(a.vault)
```
